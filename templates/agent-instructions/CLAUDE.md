# Claude Code

Read `AGENT_PROCESS.md` before starting any implementation task.

This repo uses Work Orders. The assigned Work Order defines the problem, scope,
acceptance criteria, risk tier, validation plan, and closeout requirements.

Before coding, confirm recorded human acceptance, completed dependencies, and
exclusive ownership. A filled template alone does not authorize implementation.
During implementation, stay inside scope and file follow-ons for adjacent work.
After implementation, run the project quality gate and request human verification
when the Work Order requires it.
Record evidence and required review results, then reconcile declared status
records before closeout.
