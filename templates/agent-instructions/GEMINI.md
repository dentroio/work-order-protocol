# Gemini

Read `AGENT_PROCESS.md` before starting any implementation task.

Use the assigned Work Order as the implementation contract. Do not infer scope
from chat history when the Work Order says otherwise.

Follow the Work Order lifecycle:

1. Read the Work Order.
2. Confirm recorded human acceptance, dependencies, exclusive ownership, and current state.
3. Implement within scope.
4. Validate with the listed commands or manual checks.
5. Ask for human verification when required.
6. Capture follow-ons and residual risks.
7. Record evidence and required review results; reconcile declared status records.
