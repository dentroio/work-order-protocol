# Support

Start with the [quickstart](docs/quickstart.md),
[examples](examples/README.md), and [documentation index](docs/README.md).

For protocol questions or documentation problems, open a
[GitHub issue](https://github.com/dentroio/work-order-protocol/issues).
Include the relevant guide or template, your expected outcome, the actual
problem, and a minimal sanitized example. For agent activation problems, include
the tool and version, adapter location, working directory, and activation checks
performed. Do not include raw session logs without reviewing and redacting them.

This repository documents a method; it is not the support desk for a coding-tool
vendor or for the application in which you adopt Work Orders. Tool defects should
go to that tool's official support channel. Project-specific behavior belongs
with the adopting project's maintainers.

Do not post credentials, personal information, private manuscript content, or
sensitive vulnerability details in public issues. Use GitHub private vulnerability
reporting if the repository offers it. Otherwise, ask the maintainer for a private
reporting channel without disclosing the sensitive details publicly.

Responses depend on maintainer availability. No response-time or resolution
guarantee is offered.
